# BackSense
 
**A Wearable Posture Awareness System**
 
BackSense is a wearable adhesive sensor patch that monitors lower back muscle pressure and posture in real-time, delivering vibration alerts and personalized insights through a companion mobile app.
 
Built as part of CIS 5930 Human-Computer Interaction at Florida State University.
 
## Live Demo
 
- **Project Page:** [https://furtunaae.github.io/Back-Strain/](https://furtunaae.github.io/Back-Strain/)
- **Interactive Prototype:** [https://furtunaae.github.io/Back-Strain/prototype.html](https://furtunaae.github.io/Back-Strain/prototype.html)
## Features
 
- **Real-Time Dashboard** — 3D spine visualization with live posture score and color-coded strain indicators
- **Smart Alerts** — Customizable vibration alerts with adjustable delay, intensity, quiet hours, and AI scheduling
- **Weekly Reports** — Bar charts, daily breakdowns, week-over-week comparisons, and 4-week trend tracking
- **Guided Stretches** — Personalized exercises with difficulty ratings, built-in timers, and an achievement system
- **Onboarding Flow** — Sensor pairing and calibration walkthrough for first-time users
## Tech Stack
 
- React
- Three.js (3D spine visualization)
- Recharts (data visualization)
